# Getting Started with Bolt.new: Complete Overview and Development Guide

Modern web software engineering is undergoing a fundamental shift towards agentic, prompt-driven development environments. Leading this revolution is **[Bolt.new](/tool/bolt-new/)**, an AI-powered full-stack web development workspace engineered by StackBlitz.

By leveraging WebContainer technology, Bolt.new executes Node.js environments directly inside web browsers. This enables developers and product teams to prompt, build, run, debug, and deploy complete full-stack web applications without configuring local dependencies or terminal setups.

---

## What is Bolt.new and What Problem Does It Solve?

Traditionally, scaffolding a new full-stack project required setting up local Node.js environments, configuring package managers (`npm`, `pnpm`), managing TypeScript build settings, styling engines, and running local development servers. When using standard AI coding assistants, developers often had to copy-paste code snippets back and forth between their IDE and browser.

Bolt.new solves this friction by providing a unified, autonomous browser-based environment where AI can:
1. **Scaffold Projects**: Instantly generate complete project file trees (React, Next.js, Vite, Svelte, Vue, Node backend servers).
2. **Execute Terminal Commands**: Run `npm install`, start dev servers, and execute scripts in the browser sandbox via WebContainers.
3. **Self-Correct and Debug**: Intercept runtime errors and build failures, inspect stack traces, and apply code diffs automatically.
4. **Instant Deployment**: Deploy applications directly to cloud hosting platforms like Netlify with a single click.

---

## Deep Dive into Key Capabilities

Bolt.new combines LLM intelligence with browser-native operating systems. Key highlights include:

- **Browser-Native WebContainer Execution**: Operates inside WebContainers, allowing real Node.js runtimes to execute in client-side WebAssembly sandboxes with minimal latency and high security.
- **Full-Stack File Editing**: Edits multiple files across frontend components, API endpoints, database schemas, and configuration files simultaneously.
- **Interactive Live Preview**: Provides immediate visual feedback in a side-by-side browser frame that auto-refreshes as code changes are generated.
- **Open-Source Core**: StackBlitz released the codebase under an open-source MIT license, allowing developers to self-host and customize the interface at [GitHub](https://github.com/stackblitz/bolt.new).
- **One-Click Netlify Deployment**: Streamlines publishing web applications to live production URLs within seconds.
